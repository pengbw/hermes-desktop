# 内置角色种子数据

> 角色定义文件位于 `src-tauri/resources/roles/{templateId}/{roleId}.json`
> 新增角色时：1) 创建 JSON 文件 → 2) 在 `seeds.rs` 的 `load_builtin_roles()` 中注册 → 3) 在 `project-templates.json` 的 `roleIds` 中引用

## JSON 字段说明

| 字段             | 类型            | 说明                                                       |
| ---------------- | --------------- | ---------------------------------------------------------- |
| id               | string          | 角色唯一标识，格式：`{templateId}_{角色缩写}`              |
| templateId       | string          | 所属项目模板 ID                                            |
| nickname         | string          | 角色简称（显示在头像旁）                                   |
| icon             | string          | Emoji 图标                                                 |
| name             | LocalizedString | 角色名称（zh-CN/zh-XG/en）                                 |
| description      | LocalizedString | 角色描述                                                   |
| responsibilities | LocalizedString | 职责说明                                                   |
| soulContent      | LocalizedString | 灵魂信条（注入 AI 的核心人设）                             |
| avatarPreset     | string          | 头像预设风格：business/tech/analyst/expert/creative/writer |
| avatarColor      | string          | 头像主色（HEX）                                            |

## 新增角色清单

新增角色时按以下步骤操作：

1. 在 `src-tauri/resources/roles/{templateId}/` 下创建 `{roleId}.json`
2. 在 `src-tauri/src/database/seeds.rs` 的 `load_builtin_roles()` 中添加 `include_str!`
3. 在 `src-tauri/resources/project-templates.json` 对应模板的 `roleIds` 数组中添加 roleId
4. 在 `src-tauri/resources/project-templates.json` 对应模板的 `workflows` 中添加流转关系
5. 更新本文档
