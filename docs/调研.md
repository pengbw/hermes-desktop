## Hermes Agent 异步文件生成 + 钩子回调机制

### 一、异步执行的时机

Agent 生成文件（`write_file`）是**同步阻塞**的，但**并发执行多个工具**时，工具之间是并行的（ThreadPoolExecutor）。核心在 `run_agent.py` 第 10677 行：

```python
# ── Concurrent execution ─────────────────────────────────────────
results = [None] * num_tools
for i, (tc, name, args, block_result, blocked_by_guardrail) in enumerate(parsed_calls):
    if block_result is not None:
        results[i] = (name, args, block_result, 0.0, True, True)

def _run_tool(index, tool_call, function_name, function_args):
    result = self._invoke_tool(function_name, function_args, ...)  # 各工具在独立线程执行
    results[index] = (function_name, function_args, result, duration, is_error, False)

# 线程池并发执行
with ThreadPoolExecutor(max_workers=num_tools) as executor:
    futures = [executor.submit(_run_tool, ...) for ...]
    results = [f.result() for f in futures]
```

即：**同批次多个工具并行**，但单个 `write_file` 本身是同步的。Agent 主循环是同步的，不存在真正的异步任务队列。

### 二、Callback 钩子体系

`AIAgent` 在 `__init__` 中接受以下回调，全部是**同步函数**：
Callback 触发时机 签名
tool_progress 工具开始（"tool.started"） (event, tool_name, preview, args
tool_start_c 工具实际开始执行 (tool_call_id, function_name, args
tool_complete 工具完成 (tool_call_id, function_name, args, result
thinking_c Agent 开始思考 (message
reasoning_c 推理内容增量 (text

interim_assista 流式中间响应 (assistant_msg
tool_gen_c 工具正在生成时 (tool_name, gen

### 四、文件生成完成通知的现有方案

**没有内置的"文件写完自动通知"钩子**。但有三种方式可以实现：

#### 方案 1：用 `post_tool_call` 插件钩子监听 `write_file`

```python
def on_write_file_complete(**kwargs):
    if kwargs.get("function_name") == "write_file":
        path = kwargs.get("function_args", {}).get("path")
        content = kwargs.get("function_result")
        # 发送通知、推送消息等

ctx.register_hook("post_tool_call", on_write_file_complete)
```

#### 方案 2：Gateway `background_review_callback`

在 gateway 模式下，`AIAgent.background_review_callback` 用于后台任务完成后向用户推送结果。设置在 `cli.py` 第 1191 行，但实际在 gateway 模式下由
`GatewayRunner` 注入。

#### 方案 3：`status_callback` 监听工具完成

```python
def my_status_cb(event_type, message):
    if "write_file" in message and "completed" in message:
        # 文件写完了
        pass

agent = AIAgent(status_callback=my_status_cb, ...)
```

### 六、关键结论

- **不存在原生的异步任务队列/Job 系统**。Agent 主循环是同步的，长任务用 `delegate_task` 或 `tmux` 托管子进程。
- **`post_tool_call` 是最接近"文件生成完成后"的钩子**，但需插件机制介入。
- **`tool_complete_callback` 在 Gateway 模式下未连接到消息发送**（`run_agent.py:2398` 注释写着 `gateway status_callback is not yet
wired`），所以 Gateway 里发消息要靠 `send_message` 工具或 `background_review_callback`。
- 如果你想在文件生成后主动推一条消息给用户，需要自己写一个 `post_tool_call` 插件，或者在应用层用 `cronjob` 轮询文件变化。
